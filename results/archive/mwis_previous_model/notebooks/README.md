# Frozen notebook copies

These notebook files preserve the exact versions used to generate the frozen MWIS experiment results. They are intentionally kept here as historical provenance and are separate from the working notebooks in `results/`.

The working notebooks may receive later path or usability updates. Such updates do not change these archived copies or the already-frozen results. For current runs, use the notebooks in `results/`; use this folder to identify the notebook versions associated with the frozen experiment archive.
