# MWIS run outputs

- `pipeline_results/` stores MWIS conflict graphs, component decomposition, bounds, and selected solutions.
- `reconstruction_metadata.json.gz` in each pipeline run stores the reconstruction data in losslessly compressed form to keep generated artifacts pushable to GitHub.
- `qubo_annealing/` stores QUBO construction, D-Wave simulated-annealing samples, and reconstructed schedules for the matching MWIS run.
- `experiment_comparison/` stores the tables and figures generated by `results/4_mwis_experiment_comparison.ipynb`.

Run folders use a consistent `expN_s<SATELLITES>_g<GATEWAYS>` name. Experiment 4 adds `_n<NODES>_c<COUPLERS>` for its QPU limits. Shared settings, including the four-minute minimum contact and exact-clique limit, are recorded in each run's configuration log.

CSP showcase and CSP-specific outputs remain under `results/runs/csp_showcase/`.
